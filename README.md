# D&D Companion

Локальное веб-приложение для совместной игры в Dungeons & Dragons 5e 2024.

## MVP

- редактируемый лист персонажа с ручным сохранением;
- локальные профили игрока, Мастера и Overseer без авторизации;
- кампании, участники, роли и назначения персонажей;
- игровые и неигровые персонажи;
- книга из 387 заклинаний с поиском и фильтрами;
- известные и подготовленные заклинания, лимиты и расход ячеек;
- создание и редактирование заклинаний Мастером и Overseer;
- импорт персонажа Long Story Short v2 из JSON.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
pnpm install
pnpm dev
```

Приложение откроется на `http://localhost:3000`.

## Проверка

```bash
pnpm build
pnpm test
```

Данные хранятся в локальной D1/SQLite базе. Схема находится в `db/schema.ts`, миграции — в `drizzle/`.
